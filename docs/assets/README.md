# Portföy görselleri

Bu klasör GitHub, LinkedIn ve CV sunumunda kullanılacak DublajLab görsellerinin sabit hedefidir.

Beklenen dosyalar:

| Dosya | İçerik | Önerilen boyut |
| --- | --- | --- |
| `dublajlab-editor.webp` | Video ve timeline'ın birlikte göründüğü masaüstü ekranı | 1600×900 |
| `dublajlab-template-gallery.webp` | Hazır sahne kartları ve lisans bilgisi | 1600×900 |
| `dublajlab-mobile.gif` | Mobilde yükleme, kayıt ve sonuç akışı | 720 px genişlik, 15 sn altı |

Henüz gerçek görsel eklenmemiştir. Görseller yalnızca proje sahibinin kendi çekimi/ekran kaydıyla ve kendisine ait ya da açık lisanslı videoyla hazırlanmalıdır. Tarayıcı sekmeleri, kişisel dosya yolları, erişim token'ları ve özel bilgiler paylaşılmadan önce kırpılmalıdır.

Dosyalar eklendiğinde README içindeki yorum satırlarında hazır bekleyen Markdown görsel etiketleri etkinleştirilebilir.
